# 照片选择工具 (Photo Select)

Windows 上的照片筛选工具。打开一个照片文件夹，对当前照片按一个键标记「保留」或「不要」，标记后自动跳到下一张，一口气把整批照片过完、选出最终要留的。左右方向键可以手动前后切换。

## 下载

不用装 Python，直接下载单文件绿色版双击运行：

👉 [Releases](https://github.com/shenxiangwei/photo-select/releases)

首次启动会稍慢 2–5 秒（单文件 exe 要先解压内嵌文件），之后正常。

## 从源码运行

需要 Python 3.10+ 和 Pillow：

```powershell
pip install Pillow
python photo_select.py
```

也可以命令行直接带文件夹路径打开：

```powershell
python photo_select.py "D:\我的照片"
```

## 快捷键

| 键 | 作用 |
|---|---|
| ← / → | 上一张 / 下一张 |
| 空格 / Y | 标记为「保留」 |
| X / Delete | 标记为「删除」 |
| U | 取消标记 |
| Home / End | 第一张 / 最后一张 |
| 鼠标滚轮 | 翻页 |
| Ctrl+Z | 撤销上一次标记 |
| Ctrl+A | 全部标记为保留 |
| Ctrl+Shift+A | 取消所有标记 |
| Ctrl+O | 打开文件夹 |
| Ctrl+E | 导出保留的照片 |
| F11 | 全屏 / Esc 退出全屏 |
| F1 | 帮助 |

标记后默认**自动跳到下一张**（可在「视图」菜单关闭），所以只要一直按 `空格` / `X` 就能快速过完一整批照片。

## 功能特性

- **竖屏照片方向正确**：自动应用 JPEG EXIF 朝向，手机拍的竖屏照片不再被躺平。
- **底部缩略图滑动窗口**：只显示当前照片附近的 20 张（不是整个文件夹），当前照片始终在中间并带**发光高亮**+ 右上角黄点指示；绿框 = 保留、红框 = 删除。点击任意缩略图跳转。
- **U盘 / 网盘也流畅**：大图后台解码 + 预加载当前前后若干张缓存，连续翻页不卡；顶部进度条显示当前窗口缩略图加载进度。
- **高 DPI 字体不糊不大不小**：自动检测系统 DPI 缩放（per-monitor v2），字号按 DPI 自动适配。觉得字小/字大，改源码顶部 `FONT_BOOST` 一个数即可。
- **导出带进度条**：`Ctrl+E` 把标记为「保留」的照片**复制**到目标文件夹（原名加序号防覆盖，源文件不动），后台复制 + 进度对话框 + 可取消。
- **撤销**：`Ctrl+Z` 一步步回退标记操作。
- **隐藏文件过滤**：跳过以 `.` 开头的文件（如 `.DS_Store`、`._xxx`）。

## 导出

`Ctrl+E` 会把所有标记为「保留」的照片**复制**到指定目标文件夹，源文件不受影响：

- 同名文件自动加序号 `_1` `_2` 防覆盖
- 一张都没标记会询问是否按全部保留导出
- 复制过程弹独立进度对话框，显示 `已复制 N / 总数`，可中途取消

## 自行打包 exe

```powershell
pip install pyinstaller
pyinstaller --noconfirm --onefile --windowed --name "照片选择工具" photo_select.py
```

产物在 `dist\照片选择工具.exe`。
