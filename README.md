# 照片选择工具 (Photo Select)

在 Windows 上从一堆照片里挑出最终要保留的照片。重点：**打开一张照片 → 快捷键标记 → 左右键切换**。

## 运行

需要 Python 3.10+ 和 Pillow：

```powershell
pip install Pillow
python photo_select.py
```

也可以直接把文件夹拖到脚本上，或命令行带路径：

```powershell
python photo_select.py "D:\我的照片"
```

## 快捷键

| 键 | 作用 |
|---|---|
| ← / → | 上一张 / 下一张 |
| 空格 / Y | 标记为「保留」 |
| X / Delete | 标记为「删除」 |
| U | 取消标记 |
| Home / End | 第一张 / 最后一张 |
| 鼠标滚轮 | 翻页 |
| Ctrl+Z | 撤销上一次标记 |
| Ctrl+A | 全部标记为保留 |
| Ctrl+Shift+A | 取消所有标记 |
| Ctrl+O | 打开文件夹 |
| Ctrl+E | 导出保留的照片 |
| F11 | 全屏 / Esc 退出全屏 |
| F1 | 帮助 |

标记后默认**自动跳到下一张**（可在「视图」菜单关闭），这样你只需要一直按空格 / X 就能快速过完一整批。

## 导出

`Ctrl+E` 会把所有标记为「保留」的照片**复制**到指定目标文件夹（原名加序号防覆盖），源文件不会被改动。如果你只标记了一部分就导出，只导出被标记的；一张都没标会问你是否全部保留。

## 缩略图条

底部缩略图条显示所有照片，绿色边框 = 保留、红色边框 = 删除、黄色填充 = 当前。点击任意缩略图可跳转。
